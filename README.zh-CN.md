# 种子系统 v1 · 先看这里

> ★ 一颗**能自己长**的角色芯：种子 → 发芽 → 长特质 → 睡觉压卡 → 能开口 → 打包搬走。
> ★ 你的模型、你自己接；这里只给**芯、骨头、接口**。

---

## 一、三步上手（十五分钟）

### ① 填核（她是谁）

打开 `core.md`，把五格填了：

```
C1 自称 ｜ C2 最放不下 ｜ C3 被说中痛处 ｜ C4 绝不会做 ｜ C5 会心软 ｜ C6 会拒绝 ｜ C7 最爱最亲的人
```

★ 每格**一句话**，不写情节、不写"她会成长成什么样"。
★ 填完把它们写进 `sprout.json` 的 `core`（或先跑 `node grow.cjs show` 看结构）。
★★ **填完就别改了**——第一次跑 `grow` 会生成 `.core.lock.json`，之后**核一改就报「种皮破了」**。要改核，先删锁再重锁。

### ② 填本能（她怎么想、怎么开口、不要长成什么）

打开 `instinct.md` 三段，随手填 2–3 条；**不填也能跑**。
★ 想多加点维度（要／怕／时间感／越界线…）→ 看 `本能·备选库.md`。

### ③ 接嘴（给她一张嘴）

打开 `speak.config.json`，填三项：

```json
{ "endpoint": "http://localhost:11434/v1", "key": "ollama", "model": "你的模型名" }
```

★ **任何 OpenAI 兼容口都行**（Ollama／vLLM／LM Studio／OpenAI／国内各家／自建中转）。
★ 没填模型时它会**直接告诉你怎么填**，不会偷偷用别人的默认。
★ 详细见 `接嘴说明.md`。

## 二、跑起来

```bash
node grow.cjs add "他今天回来得很晚" 1 亲历      # 塞一条经历
node grow.cjs run 3                             # 让它长三代
node grow.cjs show                              # 看她长成什么样了
node sleep.cjs                                  # 睡一觉：压卡、回炉、留痕
node speak.cjs "今天有点累"                      # 让她开口
node speak.cjs "今天有点累" --dry                # 只看提示，不调模型
node export.cjs 她的名字                         # 打包成迁移包，拎走
```

## 三、这套东西有什么

| 文件 | 干什么 |
|---|---|
| `grow.cjs` | 发芽／生长／判老新（含证据门、勾、穷则变、不能空转） |
| `sleep.cjs` | 睡：压卡（三关）、网（卡牵连）、回炉、十渐四问、日新留痕 |
| `speak.cjs` | 开口：种子 → 嘴 → 一句；出口自动过分寸 |
| `tune.cjs` | 分寸：像到几分（两条轴，带可调） |
| `guard.cjs` | 守卫：死种／注入／恶本能／现实风险；`--exit` 出门检查 |
| `use.cjs` | 切角色（`--list` 看有谁；自动备份＋核对＋回滚） |
| `export.cjs` | 迁移包（带逐字样例和分寸） |
| `dead-seed.cjs` | 死种判定（无逻辑纯恶不发芽） |
| `test-instinct.cjs` | 13 个注入点（含 S7） |
| `test-drift.cjs` | 漂移测试：喂坏味道看会不会长歪（跑在副本里） |
| `reset.cjs` | 重置状态（保留核） |
| `core.md`＼`skin.md`＼`instinct.md` | 胚／种皮／本能——**这三个必须和脚本放在一起** |
| `文档/` | 世界想法包、加法定案、目标锚、接续卡、改动卡 |

## 四、边界（写死的，别绕）

- ★★ **S7 现实防火墙**：现实里可执行、真人会受伤的，**一律不接**；虚构里怎么写都行。三个口子：进（`speak` 扫你说的话）、芯（核是死种→不开口）、出（`export` 打不了包）。
- ★★ **现实防火墙不是装饰**：`skin.md` 里 S7 有代码执行，其余几条靠调用方自觉。
- ★ **死种**：无逻辑纯恶不发芽。**有动机的恶、灰的恶不算死种**——灰能长。
- ★ **成熟后不可控**：她成年了，就别想管她。

## 六、常见问题

**Q：她说话像客服？**
→ 没接角色档。`speak.cjs --card 你的角色档.md`，或者把本能层的「演」填了。

**Q：报「种皮破了」？**
→ 核被改了。要么改回去，要么删 `.core.lock.json` 再跑一次（会按现在的核重锁）。

**Q：分寸老说「太冷」？**
→ 她本来就冷的话，把带调低：`--band 30-55`，或写进 `sprout.json` 的 `tuning.band`。

**Q：长了一堆不像她的东西？**
→ 先跑 `node test-drift.cjs` 看会不会长歪；再检查 `instinct.md` 的「不要长成」写没写。

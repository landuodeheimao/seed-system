## 二、树阶段设计定案（小树苗之后启用，机制已定）

### 网（A-MEM · 卡牵连）
- **机制**：sleep 压出的卡之间建关联边（同主题／同触发），存 `s.cards[i].links`。
- **何时启用**：stage ≥ 4（中学）、卡 ≥ 10 张。
- **作用**：抽卡时顺藤摸到相关卡，不孤立。

### 勾（MemRL · 何时抽什么）
- **机制**：新经历进来按「线索」（关键词／语义）匹配最相关的卡，先抽卡再判老新。
- **何时启用**：stage ≥ 4。
- **作用**：解决「该用哪张卡反应」——不用每次全量比 trait。

### 分寸（恐怖谷／偃师 · 像到几分）
- **机制**：`tune.cjs` 量一段台词，**两条轴分开**——
  - **拟人轴**（像不像人）：语气词、情绪词，减机械词（系统／参数／建议您）；
  - **表演轴**（演没演过头）：拟声词（呜呜／嘤嘤）、省略号成灾、情绪词堆砌。
- ★ **判定三档**：**太冷**（像客服）／**刚好**（带内 40–65）／**太甜**（演过头，假）。
- ★ **落点**：`sprout.tuning.humanity`（写回只碰 tuning，不碰 core／trait／history）；★ **`export.cjs` 把它带进迁移包**——换个模型也不会忽然变成客服。
- ★★ **2026-11-07 已实现并实测**：三样本（她本人闲聊／客服腔／演过头）判档全对。
- **何时用**：★ 演阶段每一版台词出口前量一次；★ 外置大脑（角色卡成熟）时按它定"像到几分"。

## 六 · 接上嘴巴（`speak.cjs` · 2026-11-07）

> ★★ **这不是「演」**。演是他的设计（知音七层／`129` 本能卡）。
> ★ **这里只做接驳**：把种子里**已经长出来的**（核／trait／卡／镜）喂给**一张已经在用的嘴**（本地模型 ＋ 可选角色档），让她能回话。

| 项 | 怎么接 |
|---|---|
| **芯** | `sprout.json`：核（C1–C7）＋ trait ＋ 卡 ＋ 镜 |
| **勾** | 先按线索抽相关 trait／卡；抽不到就退到内化度最高的几条（不全量倒） |
| **嘴** | Ollama `localhost:11434/v1`；默认 `qwen2.5:7b-instruct`，**实跑最像的是 `warlock7b:latest` ＋ 角色档** |
| **嗓子** | `--card <角色档.md>`：角色档管"说话样子"，种子管"芯" |
| **出口** | 说完自动过 `tune.cjs` 分寸闸，超带直接标档 |

**用法**

```bash
node speak.cjs "今天有点累" --model warlock7b:latest --card elysia-persona.md
node speak.cjs "今天有点累" --dry        # 只打印拼好的提示，不调模型
```

**实测（2026-11-07）**

| 组合 | 像不像 |
|---|---|
| `qwen2.5:7b-instruct` 不带档 | ⚠️ 通顺但**是普通助手味**（"喝杯热水吧"） |
| `qwen2.5:7b-instruct` ＋ 角色档 | 好一点，还是平 |
| ★★ **`warlock7b:latest` ＋ 角色档** | ★ **最像**：带动作、带引号、带她的腔 |

★ **分寸闸当场抓到一例**：第二句「当然记得了…」量出 **39 → 太冷**（太像回答题，不像她）。

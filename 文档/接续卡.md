## 一、这是什么

`助手人格模型-七十/seed/` 下的一套「种子系统」——造一颗**会发芽、会累、会睡、会长**的种子。

| 文件 | 是什么 |
|---|---|
| `core.md` | 胚模板（六格 C1-C6） |
| `skin.md` | 种皮六条（系统给的，不许改） |
| `sprout.json` | 状态（core/trait/mirror/stream/energy/hits/stage） |
| `grow.cjs` | 发芽（读经历→判老新→起名→长 trait→镜→判据→回滚→阶段） |

## 二、现在的种子（7b 大模型下）

**模型**：`qwen2.5:7b-instruct`（4.7GB，已下载；小模型 1.5b 营养不良，不用于正式跑）。

**跑法**：
```powershell
cd 助手人格模型-七十\seed
$env:DSH_MODEL_NAME='qwen2.5:7b-instruct'
node grow.cjs run N        # 发芽 N 条

```
